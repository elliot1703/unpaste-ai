UNPASTE / WORKSPACE STARTER KIT

Start with 01-workspace-starter.txt in a Claude Code workspace. Answer the questions and review the context file it writes. It is a starting point; keep checking and updating it as your work changes.

02-shared-github-setup.txt is an instruction for your agent to inspect your project and prepare a shared repository. It does not connect accounts or create a repository by itself. Review the files and access before approving the remote setup.

03-weekly-document.txt helps plan a repeatable document workflow. Supply examples and replace the bracketed placeholders.

04-project-worksheet.html opens in a browser. Capture what you've started, what's working and where you're stuck. It runs locally; keep a downloaded copy of your answers.

The workspace starter and weekly document prompts are from Unpaste's existing website resource library. Shared GitHub instructions were added for this kit.

This kit contains prompts and a worksheet, not the complete Store Brain, events application or video pipeline. Those examples on the training page show potential directions for your own work.
